Insights Auto-Update

How the landing page Insights section stays in sync with the Garden of Thoughts blog — without touching index.html manually.

What it does

A GitHub Action scrapes the Garden of Thoughts index page, picks the 5 most recent English posts, fetches their tags, and writes the result to posts.json in this repo.

The landing page fetches /posts.json on load and renders the Insights section dynamically. No build step. No CMS.

Flow

Trigger options

Active

Manual — GitHub Actions UI

After publishing a new post, go to the repo Actions tab, find Update Insights Posts, and click Run workflow. Takes ~20 seconds.

Future

Automatic — Cross-repo dispatch

The Garden of Thoughts publish workflow fires a repository_dispatch to this repo on each new post. Fully hands-free.

The Action also runs on a daily cron (6 AM UTC) as a safety net regardless of trigger.

To enable the hands-free version

Add one step to the Garden of Thoughts publish workflow, and one secret to the Rain repo.

1
Create a GitHub Personal Access Token (PAT) with repo scope on the account that owns the raintransformer repo.
2
Add it as a secret named RT_PAT in the Rain repo settings → Secrets → Actions.
3
Add this step at the end of the Garden of Thoughts publish workflow:
- name: Notify raintransformer
  run: |
    curl -X POST \
      https://api.github.com/repos/SherryAnalytics/raintransformer/dispatches \
      -H "Authorization: Bearer ${{ secrets.RT_PAT }}" \
      -H "Accept: application/vnd.github+json" \
      -d '{"event_type":"new-post"}'
